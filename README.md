# Botium Toys – Internal Security Audit

## Project Overview
This project is part of the Google Cybersecurity Professional Certificate.
It involves conducting an internal security audit for Botium Toys,
a fictional retail company.

## Project Objectives
- Evaluate existing security controls.
- Identify potential security risks and vulnerabilities.
- Assess compliance with PCI DSS, GDPR, and SOC principles.
- Recommend improvements to strengthen security.
- Apply cybersecurity concepts in a simulated business environment.

## Skills Demonstrated
- Security audits
- Risk assessment
- Security controls evaluation
- Compliance assessment
- Security recommendations

## Tools and Frameworks
- PCI DSS
- GDPR
- SOC 1 / SOC 2 principles
