# Botium Toys – Internal Security Audit

## Project Overview

This project is a simulated internal security audit of Botium Toys, a fictional retail company, completed as part of the **Google Cybersecurity Professional Certificate**.

The purpose of the audit was to evaluate the company's existing security controls, identify potential vulnerabilities, review selected compliance requirements, and recommend improvements to strengthen its overall security posture.

## Project Objectives

- **Evaluate security controls:** Examine administrative, technical, and physical security controls.
- **Identify security risks:** Identify weaknesses that could expose sensitive information or disrupt business operations.
- **Assess compliance:** Review selected security and data-protection requirements associated with SOC 1/SOC 2, GDPR, and PCI DSS.
- **Recommend improvements:** Develop practical recommendations to address identified security gaps.
- **Apply cybersecurity knowledge:** Practice conducting and documenting a security assessment in a simulated business environment.

## Key Findings

The assessment identified several areas requiring improvement:

- Inadequate access restrictions and least-privilege implementation.
- Weak password management practices.
- Lack of encryption for sensitive information.
- Missing disaster recovery procedures and regular data backups.
- Lack of an intrusion detection system.
- Gaps in compliance-related security practices.

Existing safeguards included firewalls, antivirus software, physical locks, CCTV surveillance, and fire detection and prevention systems.

## Recommendations

The audit identified several recommended improvements:

1. Implement least-privilege access controls.
2. Strengthen password policies and introduce centralized password management.
3. Encrypt sensitive customer and payment information.
4. Establish disaster recovery plans and regular data backups.
5. Implement an intrusion detection system.
6. Improve access management and separation of duties.
7. Review and strengthen data-protection and compliance practices.
8. Maintain existing physical security safeguards.
